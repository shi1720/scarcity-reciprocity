# Who Gets the Recovery Hour?

**Shivam Gupta · 17 October 2026**

Research companion for *Data Centre Flexibility and Small-State Agency across Indo-Pacific Power Borders*.

## Reproduce

Python 3.9+ is sufficient with the pinned dependencies in `requirements.txt`:

```sh
python3 -m pip install -r requirements.txt
python3 -m unittest discover -s tests -v
python3 src/analysis.py
python3 src/figures.py
python3 src/build_pdf.py
```

`analysis.py` runs 869 LP optimisations (five main comparisons plus three for each of 288 sensitivity configurations). Each sensitivity case is also checked using an independent earliest-deadline-first oracle. No network, credentials, paid model, GPU or proprietary dataset is needed for these results. A complete local run takes roughly a minute on an ordinary laptop; performance is not a research result.

## What is empirical, formal, and constructed

- `data/policy_ledger.csv`: original qualitative coding of five official public documents, with locators and limits. The unit is a document, not a country. An unreported term is not coded as an absent legal right.
- `data/constructed_scenarios.json`: **constructed electrical profiles**, generated by `analysis.py`; these are not observations from Singapore, Malaysia or Australia.
- `results/main.json`: LP capacities, feasible schedules and residuals.
- `results/binding_witness.json`: the critical recovery interval for the main case.
- `results/sensitivity.csv`: all 288 parameter combinations and oracle checks.
- `results/summary.json`: computation counts and maximum residuals.
- `manuscript.txt`: editable complete paper source, including 13 verified references.
- `src/build_pdf.py`: reproducible typesetting; equations and figures are generated from the source package.

The mathematical method is an application of established preemptive scheduling and linear programming. The contribution is the bilateral protection and recovery commitment, its policy comparison and an executable audit. No claim of algorithmic priority or national capacity estimation is made. No statistical population inference is drawn from a constructed parameter grid.

## Model contract

Two aggregated systems trade power in one direction. Available supply is already net of an externally chosen reserve allowance. An essential-service floor in each system is served before the new facility. A constant PUE maps IT demand to facility power. Fixed IT demand must be served hourly; flexible jobs are divisible, preemptible and have specified release times and deadlines. The flexible aggregate can burst up to twice its average flexible load. All work must finish within the 24-hour horizon. There is no storage, internal grid congestion, power-flow physics, ramping cost or endogenous price. All these omissions limit deployment claims.

The main case uses 80% flexible demand **as an illustrative assumption**, not a measured property of LLM services. The sensitivity grid includes 20%, 40%, 60% and 80%. Outputs are average IT MW, not gross data centre connection capacity.

The cancellation comparator removes all flexible-work completion requirements. It is a deliberately permissive control, not equivalent compute service and not a characterisation of the cited literature. The daily-energy bound conserves total work but relaxes release times, deadlines and instantaneous constraints. The importer-only comparator omits exporter service protection and therefore cannot be used as a bilateral commitment.

## Verification

Tests cover an independent three-variable two-bus LP, exhaustive tiny integer scheduling instances, constant-capacity and inflexible special cases, deadline sensitivity, invalid baselines, shared histories, monotonicity and rejection of admission above the computed optimum. The sensitivity pipeline independently checks LP capacities with online earliest-deadline-first scheduling. The oracle uses a small floating-point completion tolerance; its maximum discrepancy is recorded in `results/summary.json`.

Source retrieval hashes are recorded in `data/source_manifest.json` when usable local snapshots were available. Some official sites were readable through the research browser but blocked direct downloads; these are explicitly recorded. Full third-party documents are not redistributed here. See the manuscript references for the original texts. Source access and coding cutoff: 17 October 2026.
